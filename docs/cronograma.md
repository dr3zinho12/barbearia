# Cronograma de Desenvolvimento

## Cronograma sugerido (13 semanas)

| Semana | Atividade |
|---|---|
| 1 | Levantamento de requisitos e definição do escopo |
| 2 | Modelagem do banco de dados (entidades e relacionamentos) |
| 3 | Configuração inicial do projeto (Front-End, Back-End, repositório) |
| 4 | Estrutura do Front-End (identidade visual, layouts, roteamento) |
| 5 | Estrutura do Back-End (config, middlewares, utilitários) |
| 6 | Autenticação e autorização (JWT, papéis de acesso) |
| 7 | Sistema de agendamento (disponibilidade, prevenção de conflitos) |
| 8 | Área administrativa (dashboard, gestão de clientes/barbeiros/serviços) |
| 9 | Área do cliente (dashboard, agendamento, histórico, planos, perfil) |
| 10 | Testes automatizados (autenticação, autorização, CRUD, conflitos) |
| 11 | Ajustes visuais e responsividade |
| 12 | Documentação técnica e do TCC |
| 13 | Preparação da apresentação final |

## Marcos de versionamento (histórico de commits)

O repositório foi estruturado para refletir etapas de desenvolvimento naturais, cada uma correspondendo a um ou mais
commits significativos:

1. Configuração inicial do repositório (licença, gitignore)
2. Estrutura inicial do Back-End (Node.js + TypeScript + Express)
3. Configuração, utilitários e middlewares base do Back-End
4. Modelagem do banco de dados com Prisma
5. Autenticação (cadastro, login, perfil, recuperação de senha)
6. CRUD de serviços
7. Cadastro de barbeiros e horários de trabalho
8. Sistema de agendamento e prevenção de conflitos
9. Planos de assinatura
10. Área administrativa (dashboard, clientes, horários de funcionamento)
11. Script de seed com dados fictícios
12. Testes automatizados do Back-End
13. Estrutura inicial do Front-End (identidade visual)
14. Componentes reutilizáveis, layouts e páginas públicas
15. Área do cliente
16. Área administrativa completa
17. Documentação técnica e do TCC

Esse encadeamento permite que qualquer pessoa navegue pelo histórico do Git e compreenda a evolução lógica do
sistema, da infraestrutura até as funcionalidades finais.
